# Cloud Native Java EE på Red Hat-stack

Projektpaket för en svensk arkitekturhandbok om cloud native-modernisering med Podman, OpenShift, moderna databaser, köhantering, Elasticsearch och Ceph.

## Syfte

Boken hjälper lösningsarkitekter och erfarna Java EE-utvecklare att analysera, planera och driva modernisering från traditionell Java EE-, Oracle- och IBM MQ-baserad arkitektur till en mer containeranpassad, cloud native-plattform på Red Hat-stack.

## Projektstruktur

- `docs/bokspecifikation.md`
- `docs/kapitelplan.md`
- `docs/pedagogisk-canon.md`
- `docs/terminologi.md`
- `docs/projektstatus.md`
- `docs/export-metadata.yaml`
- `chapters/`
- `examples/`
- `exports/`

## Arbetssätt

Kapitel skapas ett i taget. Efter varje kapitel uppdateras canon, terminologi och projektstatus.
