# Bokspecifikation

## Titel
Arbetstitel: Cloud Native Java EE på Red Hat-stack

## Undertitel
Strategisk containerarkitektur med Podman, OpenShift, moderna databaser, köhantering, Elasticsearch och Ceph

## Språk
Svenska, med vedertagna engelska begrepp där svenska motsvarigheter saknas eller är ovanliga.

## Ämne
Cloud native-modernisering av Java EE-baserade enterprise-miljöer med Red Hat-stack.

## Syfte
Läsaren ska kunna analysera, planera och driva modernisering från traditionell Java EE-, Oracle- och IBM MQ-baserad arkitektur till en mer containeranpassad, cloud native-plattform på OpenShift.

## Målgrupp
Lösningsarkitekter och erfarna Java EE-utvecklare.

## Förkunskaper
Läsaren antas ha praktisk erfarenhet av enterprise-arkitektur, Java EE, integration, databaser och driftmiljöer. Grundläggande förståelse för containerteknik är bra men inte obligatorisk.

## Svårighetsgrad
Erfaren.

## Boktyp
Arkitekturhandbok / strategisk teknisk guide.

## Pedagogisk stil
Beslutsorienterad, scenario-baserad och pragmatisk. Fokus ligger på tradeoffs, moderniseringsmönster, anti-patterns och referensarkitektur snarare än traditionella övningar.

## Omfattning
Medel: 16 kapitel.

## Avgränsningar
Boken är inte en fullständig installationsmanual för OpenShift, Podman, Elasticsearch eller Ceph. Den prioriterar arkitekturval, införande, modernisering, styrning och operativa konsekvenser.

## Återkommande exempel eller projekt
Ett fiktivt enterprise-case där en organisation moderniserar en Java EE-baserad affärsplattform från traditionell applikationsserver, Oracle Database och IBM MQ till en containerbaserad målarkitektur på OpenShift.

## Ton och stil
Professionell, pragmatisk, erfarenhetsbaserad och enterprise-orienterad. Boken ska inte vara cloud native-evangeliserande, utan visa när olika val passar och när de inte passar.
