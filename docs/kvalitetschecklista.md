# Kvalitetschecklista för denna bok

## Språk och målgrupp
- Allt bokinnehåll ska vara på svenska.
- Engelska facktermer används där de är etablerade.
- Tonen ska passa lösningsarkitekter och seniora Java EE-utvecklare.

## Pedagogik
- Varje kapitel ska ha tydlig arkitektonisk nytta.
- Klassiska övningar ersätts med beslutsguider, checklistor och tradeoff-analyser.
- Nya begrepp introduceras kontrollerat.

## Progression
- Målbild före teknikdetaljer.
- Plattform före state och integration.
- Moderniseringsmönster före slutlig roadmap.

## Teknik och fakta
- Snabbt föränderliga produktdetaljer ska verifieras mot officiell dokumentation när kapitel skrivs.
- Exakta versioner ska dokumenteras om de används.
